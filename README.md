# Tetris

This is one of my first project that I've started when learning how to code. 

Functions:
- Creating a window
- Creating the block shapes
- Rotating the blocks
- Clearing the lane when it's full
- Adding Sounds and Music

Overall, the projects turned out well. I still wish to improve this current project with a different window or add in my own design and sounds. 

## Project layout

- `Tetris/` - the current version, split into modules (`main.py`, `settings.py`, `tetris.py`, `tetromino.py`)
  with a custom font and sprites. Run it from inside that folder: `python main.py`
- `early-version/tetris.py` - my first attempt from May 2025: the whole game in a single file,
  with plain coloured blocks. Kept to show how the project evolved.
